Las funciones por analizar fueron, $\frac{n}{\log(n)}$ una función conocida para
aproximar a $\pi(n)$, cuya cercanía fue demostrada en el teorema de los números
primos.

También, otra función cercana es $\text{Li}(n):= \int_0^n\frac{dt}{\log(t)}$, la
cual no posee una antiderivada elemental.
